# Badge

A small status or category tag, always with text, often with an icon.

## When to use it

- Post type: `primary` + `request` (Request), `info` + `event` (Event).
- Status: `success` (Done), `warning` (Pending), `danger` (Canceled), `neutral` (Draft).
- `accent`: "New", sparingly.
- For an unread count, use the count pill (a `bg-danger` circle with a number, 20px, bold 12px tabular figures). It is not implemented yet: it comes with the first component that shows a count.

## Props

`tone`, `icon`, `children`. The text stays at `caption` (14px), never smaller.
