# Avatar

A member's photo or initials, in a circle of three sizes, or in a square as wide as its container.

## When to use it

Next to a member's name: lists (`md`, 44px), comments (`sm`, 32px), profile page (`lg`, 80px). Below the `sm` breakpoint, they shrink to 36px, 28px and 64px, to leave the width to the text.

## Props

- `name`: used for the initials and the accessible name.
- `src`: optional photo.
- `decorative`: set it when the name is already written right next to it, so that it is not read twice.
- `size`: `sm`, `md`, `lg` for a circle, or `full` for a square with rounded corners, as wide as its container (size it with the container or a `max-w-*` class).
- `neutral`: without a photo, `text-subtle` on `bg-page` rather than the avatar colors.
- `placeholder`: shown instead of the initials when there is no photo.

Without a photo, the initials are shown in `text-avatar` on `bg-avatar`, the same for every member: the name next to the avatar is what identifies the member, not a color.

## Full size

For the member's own place: the cards of the members list, the member's page. The initials do not scale with the container: pass a `placeholder`, such as the profile icon. The border and the shadow, when the avatar sits on a surface, are left to the caller.

```tsx
<Avatar
  name="Jane Doe"
  size="full"
  neutral
  placeholder={<Icon name="profile" className="size-1/3! opacity-40" />}
  className="border shadow-sm"
/>
```
