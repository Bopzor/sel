# Select

A closed list of choices, built on the native `<select>` to keep the system picker on mobile.

## When to use it

To choose a value among more than five known options (category, town). Up to five options, `RadioGroup` shows everything at a glance and takes one gesture less.

## What the consumer provides

- `options`: a list of `{ value, label }`.
- `placeholder`: adds a first, non-selectable option ("Choose a category"), shown while the value is an empty string. Uncontrolled, it is chosen at first.
- The HTML props of `<select>`, as they are: `value` + `onChange(event)` for a controlled select, `defaultValue` for an uncontrolled one, `ref`, `name`, `onBlur`, `autoComplete`… The props of react-hook-form's `register()` can be spread on it. The value is an empty string while nothing is chosen.
- Outside a `Field`: an `aria-label`, like `Input`.

## Rules

- The select has no label: put it in a `Field`, which adds the label, the hint and the error. Inside a `Field`, the select takes its id, its links and its states from it; its own props override them.
- The select has the same box as `Input`: border, focus ring, and states that follow the select's `disabled` and `aria-invalid`. A `chevron-down` icon replaces the native arrow.
