# Checkbox

A 24px checkbox, its label and an optional description, all clickable. It has no error: an error goes on a [`Fieldset`](?path=/docs/components-forms-fieldset--docs) around the checkbox.

## When to use it

- For options independent from one another, or an acceptance (charter, terms).
- For a setting that applies immediately, prefer `Switch`.

## What the consumer provides

- `label`: an affirmative sentence that describes the checked state ("Show my phone number").
- `description`: a consequence or a detail, in `text-muted`. It is not part of the checkbox's name: it is linked to it with `aria-describedby`, and read after the name and the state.
- The HTML props of `<input type="checkbox">`, passed to the native input that Ark UI keeps visually hidden: `checked` + `onChange(event)` for a controlled checkbox, `defaultChecked` for an uncontrolled one, `ref`, `name`, `onBlur`, `value`, `required`, `disabled`. The props of react-hook-form's `register()` can be spread on it.
- `aria-invalid`: when a required box is not checked. The box turns `border-danger`; the error message goes on the `Fieldset` around it ("Accept the terms to continue").

The box is 24px, the hit area 44px high: stack checkboxes in a `flex flex-col gap-4`.
