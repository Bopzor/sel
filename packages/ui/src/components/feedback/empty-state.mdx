# EmptyState

An empty screen or block that explains what will appear here and offers the first action.

## When to use it

When a list is empty (no request, no exchange, a search with no result).

## Parts

```tsx
<EmptyState icon="search">
  <EmptyStateTitle>No results</EmptyStateTitle>
  <EmptyStateDescription>Try other words, or broaden the search.</EmptyStateDescription>
  <EmptyStateAction>
    <Button variant="secondary">Clear the search</Button>
  </EmptyStateAction>
</EmptyState>
```

- `EmptyState` (required): `icon`, the icon of the content type.
- `EmptyStateTitle` (required): what is missing, in one sentence. A heading of `level` 1, 2, or 3 (2 by default, to adjust to the page hierarchy).
- `EmptyStateDescription`: why, or what will happen.
- `EmptyStateAction`: a `Button` that helps get out of it (post, broaden the search).
