# Stepper

A progress indicator for a multi-step flow: "Step 2 of 3", the name of the step and a segmented bar.

## When to use it

For any flow longer than one screen: sending units, signing up, creating an event. Three to five steps at most.

## Props

- `steps`: short names of the steps.
- `current`: number of the current step (starting at 1).
- `progressLabel`: the progress in words, in the application's language ("Step 2 of 3").

The names of all the steps are shown from 768px.
