# Tabs

Tabs to switch between views of the same content, horizontally scrollable on mobile.

## When to use it

For two to five views of the same level (Requests / Events / Information). Not to chain steps: use `Stepper`.

## Parts

```tsx
<Tabs.Root value={value} onChange={setValue}>
  <Tabs.List aria-label="Views">
    <Tabs.Tab value="requests">Requests</Tabs.Tab>
    <Tabs.Tab value="events">
      Events <Badge>2</Badge>
    </Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="requests">…</Tabs.Panel>
  <Tabs.Panel value="events">…</Tabs.Panel>
</Tabs.Root>
```

- `Tabs.Root` (required): `value` + `onChange(value)`, or `defaultValue` for uncontrolled tabs.
- `Tabs.List` (required): the tabs, named by its `aria-label`.
- `Tabs.Tab` (required): the name of a view and its `value`. A `Badge` may follow the name, such as a count.
- `Tabs.Panel`: the view of the tab with the same `value`. Only the active panel is rendered.

Height 48px, active tab in `text-primary` with a 3px `bg-primary` underline. Built on Ark UI: arrow keys move between tabs, and the active tab is linked to its panel.
