# Tabs

Tabs to switch between views of the same content, horizontally scrollable on mobile.

## When to use it

For two to five views of the same level (Requests / Events / Information). Not to chain steps: use `Stepper`.

## Parts

```tsx
<Tabs value={value} onChange={setValue}>
  <TabList aria-label="Views">
    <Tab value="requests">Requests</Tab>
    <Tab value="events">
      Events <Badge>2</Badge>
    </Tab>
  </TabList>
  <TabPanel value="requests">…</TabPanel>
  <TabPanel value="events">…</TabPanel>
</Tabs>
```

- `Tabs` (required): `value` + `onChange(value)`, or `defaultValue` for uncontrolled tabs.
- `TabList` (required): the tabs, named by its `aria-label`.
- `Tab` (required): the name of a view and its `value`. A `Badge` may follow the name, such as a count.
- `TabPanel`: the view of the tab with the same `value`. Only the active panel is rendered.

Height 48px, active tab in `text-primary` with a 3px `bg-primary` underline. Built on Ark UI: arrow keys move between tabs, and the active tab is linked to its panel.
