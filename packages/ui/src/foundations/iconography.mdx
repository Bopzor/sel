# Iconography

The system does not depend on a specific icon library. The package uses Lucide; it could switch to another outline library, as long as a single one is used and these rules are followed:

- Outline style, 24px, a single stroke width for the whole application (2px, Lucide's default). Icons take the text color (`currentColor`).
- Sizes: 16px (`size-icon-sm`) in badges, captions and small buttons, 20px (`size-icon-md`) in buttons, fields and alerts, 24px (`size-icon-lg`) in navigation, lists and icon buttons.
- An icon goes with a label. Only close, search, menu and add can appear alone, with an accessible name.
- The application goes through the `Icon` component, which takes a **concept name** and translates it to the library. Changing the library then touches a single file (`src/components/icon.tsx`).

## Concepts

| Concept         | Meaning              | Lucide                |
| --------------- | -------------------- | --------------------- |
| `request`       | Request              | `hand`                |
| `event`         | Event                | `calendar`            |
| `information`   | Information post     | `message-square-text` |
| `exchange`      | Exchange             | `arrow-left-right`    |
| `members`       | Members              | `users`               |
| `profile`       | Profile              | `user`                |
| `notifications` | Notifications        | `bell`                |
| `settings`      | Settings             | `settings`            |
| `info`          | Information (status) | `info`                |
| `success`       | Success              | `circle-check`        |
| `warning`       | Warning              | `triangle-alert`      |
| `error`         | Error                | `circle-alert`        |

The `Icon` component also defines generic concepts for actions (`add`, `close`, `search`, `menu`, `edit`, `delete`, `send`…), directions (`next`, `back`, `chevron-*`) and objects (`location`, `phone`, `email`, `time`…). The [Icon](?path=/docs/components-display-icon--docs) page lists them all.

A new feature (loans, for example) gets its concept and icon in this table before appearing in a page. Icons have a single, outline version. The active navigation entry stands out with its `bg-primary-subtle` pill and its `text-primary` color, not with a different icon.
